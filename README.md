# 가사봄 (GASABOM)

일본어 원문·한글 발음·한국어 뜻을 함께 보며 로컬 MP3로 연습하는 개인용 웹앱입니다. React 19·Next.js 16 App Router·TypeScript를 사용합니다. DB·로그인·클라우드·외부 번역/음원 API 없이 실행합니다.

## 실행

Node.js 20.9 이상이 필요합니다. 최초 의존성 설치에는 인터넷 연결이 필요합니다.

```powershell
npm ci
npm run dev
```

접속은 **http://127.0.0.1:3000**입니다. 프로덕션 실행은 `npm run build` 후 `npm start`입니다. 두 실행 방식 모두 127.0.0.1에 바인딩합니다. 다른 포트는 다음처럼 직접 전달할 수 있습니다.

```powershell
node node_modules/next/dist/bin/next dev --hostname 127.0.0.1 --port 3001
```

브라우저 기록은 호스트·포트별로 구분되므로 평소 접속 주소를 유지하세요.

## 현재 화면과 재생

- 홈 `/`: 가사 연습 안내와 등록곡 미리보기.
- 보관함 `/library`: 검색·필터·정렬·카드/목록, 즐겨찾기·학습 기록·실제 재생 통계.
- 연습실 `/songs/[id]`: 같은 행의 원문·발음·뜻, 현재 줄 중앙 이동, 한 줄 반복, 학습 체크, 노트·단어.

재생기는 **하단 하나만** 사용합니다. 페이지를 이동해도 재생 위치와 음량을 유지하며, 새로고침만으로 자동 재생하지 않습니다. 기본은 **현재 곡 반복**입니다. 한 줄 반복은 하단 아이콘 또는 가사 행의 반복 아이콘으로 조작하고, 해제하면 현재 곡 반복으로 돌아갑니다.

이전/다음 가사 줄·±5초·재생/정지·줄 반복은 아이콘 버튼이고 진행 위치·음량은 슬라이더입니다. 재생 방식 셀렉트는 없습니다. 속도는 1배입니다. 암기 모드·북마크·셔플·A–B·배속·집중·측면 패널 토글·플레이리스트 UI는 제거했습니다. 노트·단어 패널은 항상 표시하며 모바일에서는 가사 아래에 이어집니다.

단축키는 `Space` 재생/정지, `←`·`→` 5초 이동, `R` 현재 줄 반복 켜기/끄기입니다. 입력창과 버튼의 키보드 조작은 가로채지 않습니다.

## 곡 자료와 기록

곡은 `content/songs/<song-id>.json`, MP3는 `public/audio/`, 커버는 `public/covers/`에 보관합니다. 음원이 없으면 `audioSrc`를 빈 문자열로 두고 수동 가사 연습을 할 수 있습니다. 시간은 모든 줄에 있거나 모두 없어야 하며, 겹치지 않는 초 단위 숫자입니다. 잘못된 JSON은 해당 곡만 제외하고 정상 곡은 계속 표시합니다.

정식 필드는 `ja`, `koPronunciation`, `koTranslation`, `start`, `end`입니다. 사용자가 작성한 학습 텍스트와 기존 id를 보존하며 생성·번역·추출하지 않습니다. 템플릿은 `content/songs/_TEMPLATE.json`, TXT 형식은 `content/txt/example.txt`를 참고하세요.

```powershell
npm run import:txt -- content/txt/내곡.txt
npm run validate:data
```

등록·복원한 MP3와 커버는 서버를 재시작하지 않아도 제공됩니다. 로컬 파일 제공 API가 Range 구간 요청·HEAD·변경된 파일의 캐시 확인을 처리합니다.

학습 기록과 보기 옵션은 `gasabom:practice:v2` localStorage에 저장합니다. 음량(기본 100%)·재생 방식은 `gasabom:session:v1` sessionStorage를 사용합니다. 기존 북마크·플레이리스트 데이터와 이전 v1 기록은 삭제하지 않습니다. 손상된 기록 원본은 `gasabom:practice:recovery`로 보존합니다.

## 숨긴 설정과 개발 기준

설정은 현재 사용하지 않아 메뉴와 화면의 진입 링크를 숨겼습니다. `lib/features.ts`의 `SETTINGS_VISIBLE=false`가 기준입니다. `/settings` 코드·직접 주소 접근·로컬 자료 관리 API는 유지합니다. 다시 사용할 때 true로 바꾸면 진입 링크를 표시합니다.

보존된 관리 기능은 곡 등록·편집·삭제·시간 초안, 노트/단어 편집, 학습 기록 JSON과 곡 자료 ZIP 백업·복원입니다. MP3 100MB, JSON/TXT 10MB, ZIP 250MB 제한, 동일 출처·loopback·경로/내용 검사, 저장 버전 충돌·원본 복구, 복원 목록/충돌/해시 검증을 적용합니다. 곡 삭제는 연결 MP3·커버를 보존합니다. OS/디스크 고장·강제 종료에 대한 완전한 다중 파일 원자성은 보장하지 않습니다.

## 이 PC의 자료와 Git

이 PC의 등록곡은 Pretender 1곡, 가사 74줄·표현 39개입니다. 편집 음원은 318.53초이며 타임코드는 이미 보정되어 있습니다. **가사·발음·뜻·시간은 전사 초안으로 공식 자료 대조와 전체 청음 검수가 남아 있습니다.** 자체 일러스트 커버를 사용합니다.

Git에는 코드·현재 문서·실행에 필요한 자체 웹 에셋·템플릿을 보관합니다. 개인 MP3·곡 JSON/TXT·브라우저 기록이 담긴 검수 파일과 디자인 원본은 제외하고 로컬에 보존합니다. 새로 복제하면 빈 보관함으로 시작하므로 개인 자료를 폴더에 등록하거나 보존된 관리 기능으로 복원하세요.
