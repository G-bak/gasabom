# 로컬 Pretendard

사용자 지시에 따라 공식 Pretendard v1.3.9의 Variable WOFF2를 프로젝트에 직접 저장했다. `app/layout.tsx`에서 `next/font/local`로 연결한다. 브라우저는 이 앱의 로컬 주소에서 폰트를 받아 사용하며 외부 CDN에 접속하지 않는다.

- 공식 저장소: https://github.com/orioncactus/pretendard
- 파일: https://github.com/orioncactus/pretendard/blob/v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
- 굵기: 100~900
- 라이선스: SIL Open Font License 1.1, 이 폴더의 `OFL.txt` 원문 보관.
