# 01. 서비스 기획서 / PRD

## 1. 제품 비전

가사봄은 일본어 실력을 평가하거나 가사를 자동 번역하는 학습 프로그램이 아니다. **'이미 알고 있고 좋아하는 한 곡을 잘 부르기 위해 눈과 귀를 함께 쓰는 도구'**이다. 언어 학습 앱보다 **내 노래 연습실**에 가깝게 설계한다.

### 핵심 JTBD (Jobs To Be Done)

> 일본어를 못 읽지만 원하는 J-POP을 따라 부르고 싶을 때, 내가 마련한 한글 발음과 일본어 원문을 음악의 현재 부분에 맞춰 보고, 어려운 문장을 반복하여 외우고 싶다.

## 2. 대표 사용자 / 이용 상황

- 한국어가 익숙하고 일본어 가나·한자를 읽지 못할 수 있다.
- 사전 학습보다 **노래 한 곡 완창**이 목표다.
- 데스크톱에서 가사를 준비하고, 음악을 들으며 연습한다.
- 짧은 반복 연습이 많고 가사 단위로 체크하고 싶다.
- 데이터나 외부 유출을 원하지 않으며 로컬 사용을 선호한다.
- 정확한 시간 정보를 만들기 번거로울 수 있으므로 **수동 보기 모드**가 필수다.

## 4. 화면 우선순위

### 4.1 보관함 `/`

목적: 곡을 선택하기까지의 탐색 비용 최소화.

- 대표 카피와 '지금 연습 시작' CTA.
- 등록곡 수, 외운 줄, 즐겨찾기 곡 수.
- 카드: 커버 아트, 제목, 가수, 장르/난이도, 외운 줄 비율.
- 검색과 즐겨찾기 필터.
- 곡 추가 가이드 링크.
- 빈 화면: 추가한 곡 없을 때 도움말.

### 4.2 연습실 `/songs/[slug]`

목적: 듣기·읽기·발음·뜻·암기를 한 작업 흐름으로 묶음.

- 최상단: 곡 제목, 설명, 난이도, 가사 총줄 수, 학습 체크률.
- 가사: 원문 / 한글 발음 / 해석을 한 줄의 묶음으로 표시.
- 원문/발음/해석 토글.
- 암기 도전: 발음·뜻 가림 → 가사 누르면 내용 공개.
- 클릭한 가사로 이동(타임코드가 있을 때).
- 외운 줄 체크 버튼(노래 위치 이동과 구분).
- 한 줄 반복 버튼(타임코드 + MP3 조건).
- 오른쪽: 학습 사용 팁 / 구간 반복 A·B / 단축키.
- 하단 고정 플레이어: 재생/탐색/속도/음량.
- 모바일: 플레이어는 바닥에 유지, 보조 팁은 숨기되 필수 재생기 유지.

### 4.3 가이드 `/guide`

목적: JSON을 처음 작성하는 사용자의 실수 감소.

- MP3 파일 경로 예시.
- 곡당 JSON 파일 구조 예시.
- 새로고침 방법.
- 타임코드 선택사항과 누락 상태 안내.
- TXT 변환 방법.
- '자동 번역 없음'을 명확히 전달.

## 5. 학습 흐름 설계

### 기초 모드 — 읽어보기

원문·한글 발음·뜻 3단을 함께 표시한다. 발음이 시각적으로 더 강하다. 노래를 재생하고 눈으로 현재 문장을 따라간다.

### 연습 모드 — 속도 낮추기

0.75/0.85배속으로 조정, 어려운 가사 줄을 누른다(타임코드 있을 때). 반복 버튼으로 같은 소절을 듣는다.

### 암기 모드 — 외워보기

암기 도전을 켜면 일본어만 보이고 발음·뜻은 숨긴다. 사용자에게 원문을 읽도록 강요하기보다 **음원을 듣고 소리로 떠올려 보도록** 유도한다. 확인할 때는 해당 가사 줄을 눌러 발음/뜻을 연다. 원문 가림 기능은 현재 범위에 포함하지 않는다.

### 완료 표시 — 체크하기

외웠다고 생각한 문장을 수동 체크한다. 체크는 절대적인 발음 정확도/실력 판정이 아니라 개인 기록이다.

## 6. 기능 정책과 예외

| 상태 | 정책 |
| --- | --- |
| JSON만 있고 MP3 없음 | 모든 가사 표시/암기/체크 가능. 재생 UI 비활성. |
| MP3는 있지만 타임코드 없음 | MP3 재생/속도 조절/A–B 수동 지정 가능. 가사 줄 자동 강조/줄 이동·줄 반복 불가. |
| MP3+타임코드 | 모든 연습 기능 사용. |
| 타임코드 일부만 입력 | `validate:data`에서 오류 처리. |
| JSON 형식 불량 | 검증 스크립트에서 오류. 개발 UI에서는 관련 예외 메시지. |
| `audioSrc`가 틀림 | 재생 실패 안내와 가이드 링크 표시. |
| localStorage 차단 | 저장 실패를 무시하고 현재 페이지에서는 가능한 범위로 동작. |
| 구간 설정에서 B ≤ A | 반복을 시작하지 않고 재설정 메시지 표시. |
| 암기 모드에서 표시 토글 | 표시 토글은 일시 비활성; 암기 모드 해제 시 이전 사용자 설정 유지. |
| 가사 전체가 빈 배열 | 크래시하지 않고 빈 상태 안내. |

## 7. 비기능 요구사항

- 개인 PC에서 일반적인 데스크톱/모바일 화면을 지원하는 반응형.
- HTML button / label / input range 등 표준 컨트롤로 키보드 접근 가능.
- 반복·진행 상태는 사용자가 이해할 수 있는 라벨로 노출.
- 외부 API 호출 없음(React/Next 의존성 최초 설치 제외).
- 서버 사이드 파일 접근과 브라우저 오디오 기능을 명확히 분리.
- 데이터/노래 파일은 사용자가 소유하고 유지할 수 있어야 함.
- 디자인은 한글 발음 가독성과 명확한 대비 우선.

## 8. 우선순위상 의도적으로 생략한 UX

복잡한 파일 업로드 모달, 자동 타임코드 추출, AI 발음 점수, 구절별 녹음, 음원 분리, 플레이리스트 공유, 회원 관리. 장기적으로 가능하더라도 **본 요청의 범위에서는 구현하지 않는다**.
