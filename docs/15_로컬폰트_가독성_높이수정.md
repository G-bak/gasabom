# 15. 로컬 폰트·가독성·높이 제한 수정

2026-10-10 사용자 요청 반영.

가사 패널에 적용했던 PC 59vh/710px, 모바일 56~58vh, 집중 모드 65~68vh 최대 높이를 제거했다. 가사 전체를 문서에 표시하고 페이지 전체로 스크롤한다. 노트와 JSON 형식 안내의 최대 높이도 제거했다. 로고 이미지 크기 제한은 콘텐츠 높이와 별개로 유지한다.

이전 CSS는 Pretendard 이름만 선언했으며 실제 파일이 없어 시스템 글꼴을 사용했다. [공식 Pretendard v1.3.9](https://github.com/orioncactus/pretendard/releases/tag/v1.3.9)의 Variable WOFF2(2,057,688바이트)를 `app/fonts`에 저장하고 `next/font/local`로 연결했다. SIL OFL 1.1 라이선스 원문도 보관했다. 폰트는 localhost의 `/_next/static/media/*.woff2`에서 로드되며 외부 폰트 CDN에 의존하지 않는다.

- 본문 16px, 보조 글자 최소 14px. 작은 버튼·설명·모바일 글자도 확대했다.
- 한글 발음 기본 24px, 설정 조절 범위 20~32px. 이전 20px 미만 기록은 새 기본값으로 조정하며 다른 학습 기록은 보존한다.
- 가사 원문·뜻 PC 20px, 모바일 18px.
- 자동 스크롤은 내부 패널에서 페이지 전체 이동으로 변경했다. 첫 진입 시 히어로를 건너뛰지 않으며 선택 줄이 이미 보이면 위치를 유지한다.
- 캐시된 MP3 메타데이터가 React 이벤트 연결 전에 도착해 길이 0:00으로 보이는 경우를 수정했다. 최초 연결 시 이미 읽힌 길이를 반영한다.
- 큰 글자로 인해 모바일 보관함이 넓어지던 그리드 최소 너비 문제도 수정했다.

검증: 데이터 3곡 오류·경고 0건, 타입 검사·프로덕션 빌드 통과. 1440/1024/768/390px의 홈·보관함·설정·연습실에서 최종 가로 넘침 없음. 브라우저에서 Pretendard loaded와 로컬 WOFF2 경로를 확인했다. 가사 패널 max-height=none, overflow-y=visible, clientHeight=scrollHeight를 확인했다. 모바일 12번 줄 선택 시 페이지가 이동하고 내부 scrollTop은 0이었다. MP3 48초·0.75배속·0~4초 반복 복귀, 암기 공개 시 위치 유지, 수동 가사 표시·재생 비활성도 확인했다. 최종 콘솔 오류 0건.
