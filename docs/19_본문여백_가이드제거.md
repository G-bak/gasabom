# 19. 본문 여백 변경과 가이드 제거

2026-10-10 사용자 요청 반영.

- PC .container를 `width: calc(100% - 240px); max-width: none; margin: 0 auto;`로 변경했다. 본문 좌우 여백은 120px이다. 기존 좁은 화면 분기는 유지해 1050px 이하 20px, 모바일 16px 여백을 사용한다.
