# 18. 시안 재검토·확장 배경·곡 커버·표현 자료

2026-10-10 사용자 요청 반영.

## 시안과 화면 구성

`design/01_가사봄_홈_디자인.png`부터 `04_가사봄_곡등록_데이터관리_디자인.png`까지 네 장을 다시 열어 확인했다. 기존의 전체 폭 사용, 로컬 Pretendard, 기능 중심 한국어 문구 기준은 유지했다.

- 홈: 학습 카드 사이의 진행 표시, 작은 곡 커버 카드 행, 파란색 버튼과 밝은 카드.
- 보관함: 좌측 분류/플레이리스트, 가운데 곡 목록, 우측 연습 현황과 자주 듣는 아티스트.
- 연습실: 원문·발음·뜻의 세 카드와 우측 노트/표현, 짙은 남색 하단 재생기. 같은 가사 줄은 한 DOM 행으로 관리해 대응 관계와 선택·반복·암기 상태를 유지한다.
- 자료 관리: MP3/JSON/TXT 세 카드, 우측 형식 안내, 아래 자료 목록과 미리보기. 미리보기의 파란 세로 표시와 카드 스타일을 맞췄다.

참조 이미지의 문학적인 홍보 문구나 가짜 곡/가수/통계는 넣지 않았다. 현재 등록곡은 실제 예시곡 3개이며 카드의 빈 자리와 아티스트 기록은 실제 자료 수에 따른다.

확장 배경은 왼쪽 여백을 두고 도시/창가 구도를 새로 그렸다. 1921px 이상에서 새 확장 구도를, 일반 PC·모바일에서는 기존 구도를 선택한다. 각 확장 구도는 2560/3840px × AVIF/WebP로 출력했다(총 16개).

**실제 생성 배경 원본은 2172×724px이다. 3840px 파일은 새 구도로 생성한 원본을 확대·크롭해 출력한 웹 버전이며, 네이티브 4K 생성 원본은 아니다.** 커버 생성 원본은 1254×1254px, 웹 커버는 1024×1024px다. 원본 PNG를 모두 보존했다.

곡 커버는 야경의 편지·벚꽃길·우산이 있는 빗길로 각각 새로 만들었다. 배경 이미지를 잘라 재사용하지 않는다. 세 곡의 coverSrc를 연결했으며 커버 미지정/로드 실패 시 기본 커버도 새 곡 커버를 사용한다.

## 연습실

`section-label`과 `lyrics-panel-tools` 요소를 JSX에서 제거했다. CSS로 숨겨 둔 것이 아니다. 원본 JSON의 section 값은 보존한다. 언어 보기 설정은 설정 화면에 남겨 두었다.

세 가사 카드는 높이 제한 없이 전체 문서로 스크롤한다. 카드마다 같은 줄 번호를 표시하고, 긴 발음/번역에도 같은 행의 세 셀 높이를 맞춘다. 모바일은 한 줄 안의 세 언어를 세로로 표시하며, 긴 한글 발음이 줄어들어 뜻과 겹치던 부분도 높이 자동 계산으로 수정했다.

노트는 작성/저장한 노트 탭으로 구분했다. 저장하면 저장 목록으로 전환되고 기존 브라우저 기록은 유지한다.

## 어려운 표현

사용자의 목록 작성 지시에 따라 현재 예시 3곡에 곡별 4개, 총 12개 표현 자료를 직접 작성했다. 일본어, 일본어 읽는 법, 한글 발음, 한국어 뜻, 연결 가사 줄 id를 studyWords에 넣었다. 전체 가사·발음·뜻·줄 id는 변경하지 않았다.

- 화면을 열면 곡 자료의 표현 4개를 바로 표시한다.
- 음원/시간 정보가 있으면 해당 줄의 구간을 반복 재생한다.
- ‘단어장에 모두 추가’ 또는 별표로 내 단어장에 저장하며 중복을 막는다.
- 이미 저장한 단어와 곡의 표현 자료를 중복 표시하지 않는다.
- 음원/시간 정보가 없는 곡은 텍스트 표시와 저장은 제공하고 구간 재생 버튼은 비활성화한다.

자동 번역·음역·표현 추출 서비스를 추가한 것이 아니다. 새 곡은 직접 작성한 studyWords 또는 수동 추가 단어를 사용한다. 스키마 안내는 [05번 데이터 가이드](05_데이터_작성_가이드.md)를 따른다.

## 자주 듣는 아티스트

기존 ‘가수별 곡 수’를 제거했다. 브라우저 기록의 곡별 playCounts를 가수별로 합산해 재생 횟수 순으로 상위 5명을 표시한다. 기록이 없으면 빈 기록 안내를 표시한다. 아티스트에 등록된 곡 수를 청취 빈도로 바꾸어 표시하지 않는다.

곡을 처음 재생하거나 종료 후 다시 시작하면 집계한다. 같은 연습 화면에서 일시정지 후 이어 듣기와 구간 반복은 같은 재생 세션으로 취급해 중복 집계하지 않는다. 이전 v2 기록에 playCounts가 없으면 빈 기록으로 이관하며 기존 기록은 보존한다.

## 검증

- 데이터 검사: 3곡, 오류/경고 0건. 표현 id·필수 문자열·연결 줄 id를 검증한다.
- 타입 검사·프로덕션 빌드 통과, 최종 브라우저 콘솔 오류 0건.
- 3840/2560/1440/1024/768/390px의 네 화면 24개 조합: 가로 넘침·깨진 이미지 없음.
- 3840px에서 실제로 새 3840px AVIF 배경을 선택. 일반 PC/모바일은 해당 기존 파일 선택.
- section-label/lyrics-panel-tools DOM 개수 모두 0.
- 세 가사 카드의 동일 행 높이/위치 확인. 모바일 원문·발음·뜻의 scrollHeight/clientHeight 일치와 겹침 없음 확인.
- 표현 일괄 추가 후 4개 저장·4개 표시, 중복 추가 비활성. 별표 저장·새로고침 유지, 연결 음원 구간 재생 확인.
- 실제 재생 후 아티스트 2회 표시, 이어 듣기 후 2회 유지.
- 마지막 44~48초 줄을 0.75배속으로 반복하며 복귀 확인, 같은 세션의 재생 횟수 1회 유지.
- 암기 정답 공개 전후 0초 유지, 숨긴 항목 24개→22개. 음원 없는 곡의 표현 4개 표시 및 재생 비활성 확인.
- 노트 저장 후 저장한 노트(1) 탭으로 전환 확인.

검수용 브라우저 기록은 작업 전 기록으로 복구했다. 최종 프로덕션 서버는 127.0.0.1:3000에 실행해 두었다.
