# 06. 오디오 플레이어 / 가사 동기화 / 학습 UX 상세 설계

> 2026-10-10 최신 동작: 매 줄 중앙 자동 스크롤, 네 가지 재생 모드, 기본 음량 100%와 음량·재생 방식·플레이리스트의 탭 세션 저장을 적용했다. [21번 변경 기록](21_중앙스크롤_음원편집_재생모드_세션저장.md)이 아래 최초 설계보다 우선한다.

## 1. 왜 HTMLAudioElement인가

사용자는 MP3 파일을 직접 준비하며, 음악 스트리밍 플랫폼을 만들 생각이 없다. 기본 HTML5 `<audio>`가 제공하는 `play()`, `pause()`, `currentTime`, `duration`, `volume`, `playbackRate`로 요구한 기능을 구현할 수 있다.

별도 음악 서비스 SDK, DB, 음원 분석 서버, 음성 판정 API는 필요 없다.

## 2. 오디오 상태 모델

| 상태 | 주요 데이터 | 화면 |
| --- | --- | --- |
| `idle` | MP3 지정/미지정 | 재생 가능 여부 안내 |
| `loading` | 메타데이터 대기 | 재생 시간 0:00 표시 가능 |
| `ready` | duration 확보 | 탐색 가능 |
| `playing` | audio.paused = false | 일시정지 아이콘 |
| `paused` | audio.paused = true | 재생 아이콘 |
| `error` | 오디오 로드/재생 실패 | 오류 배너 + 가이드 링크 |
| `ended` | 음원 종료 | 비반복 시 일시정지, 반복 시 시작점으로 복귀 |

## 3. 재생 컨트롤 명세

- 중앙 메인 컨트롤: 재생/일시정지.
- 탐색바: 현재 위치/전체 시간을 `분:초`로 표시, `input[type=range]` 드래그.
- `-5s` / `+5s`: MP3 기준 위치 이동. 파일 경계를 넘으면 0 또는 duration으로 제한.
- 이전/다음 줄: 타임코드가 있으면 해당 줄 시작점으로 이동. 타임코드 없으면 **수동 선택된 줄 번호만** 변경.
- 속도: 0.75x / 0.85x / 1.0x / 1.15x / 1.25x.
- 볼륨: 0.0 ~ 1.0, 0.05 단위.
- 타임코드가 없는 곡도 MP3 자체가 있으면 오디오 탐색/수동 A–B 반복 가능.
- 음원이 미등록되면 재생/탐색/반복은 비활성, 나머지 기능은 작동.

### 속도와 피치

`playbackRate` 변경으로 속도를 조정한다. `preservesPitch = true`를 사용해 가능한 브라우저에서 음높이 보존을 요청한다. 브라우저·코덱 환경에 따라 느린 배속에서 음질 또는 음성 톤에 차이가 날 수 있다. 전문 보컬 신호처리 엔진을 구현한 것은 아니다.

## 4. 타임코드 동기화 상세

입력:

```json
{ "start": 65.1, "end": 68.7, "ja": "...", "koPronunciation": "...", "koTranslation": "..." }
```

알고리즘:

```text
if (allLinesHaveValidTimecodes && audioFileIsSpecified && audioMetadataLoaded):
    t = audio.currentTime
    active = first line whose start <= t < end
    if active is missing:
        active = last line whose start <= t
    if still missing:
        active = first line
else:
    active = last manually selected line
```

시각 효과:

- 활성 줄의 전체 카드 배경을 은은한 보라색으로 강조.
- 일본어·한글 발음의 대비를 조금 높임.
- `autoScroll === true`이면 가사 컨테이너 안에서 중앙 근처로 스크롤.
- 가사 전체 목록을 빠르게 읽을 수 있도록 행의 수동 클릭을 허용.

### 동기화 데이터의 핵심 제한

**음원을 분석해서 자동으로 시각을 만드는 기능은 없다.** `start`/`end`는 사용자가 수동으로 작성한 정답 데이터다. 노래/음원 버전이 달라지면 새 시각으로 수정한다.

## 5. 한 줄 반복 동작

- 사용자: 특정 줄 오른쪽의 `↻` 버튼 클릭.
- 전제: `audioSrc`에 MP3가 있고 전체 줄에 타임코드가 있어야 함.
- 시스템: `loopStart = line.start`, `loopEnd = line.end`, `loopActive = true`.
- 즉시: 현재 음원을 `loopStart`로 이동하며, 일시정지 중이었다면 재생을 시작.
- 재생 중: `audio.currentTime >= loopEnd`가 되면 `loopStart`로 점프.
- 한 줄 반복 중 다른 줄의 반복 버튼을 클릭하면 새 구간으로 교체.
- 활성 반복 버튼(하단)을 다시 클릭하면 `clearLoop()`로 반복 해제.

브라우저 처리 특성상 0ms 단위로 샘플 정밀한 루프를 제공하지는 않는다. 악기 연주/고정밀 음악 제작 프로그램과 달리 **가사 암기를 위한 충분히 짧은 반복**이 목적이다.

## 6. 수동 A–B 구간 반복

### 단계

1. 음원 재생 위치를 원하는 시작점으로 이동.
2. `A 설정` 클릭: `loopStart` 저장, 기존 B/반복 해제.
3. 끝내고 싶은 시각으로 탐색.
4. `B 설정` 클릭: B가 A보다 0.2초 이상 뒤에 있을 때 저장.
5. A~B 구간 반복 시작(정지 상태였다면 재생 시작).
6. `초기화` 클릭: A/B/반복 상태 제거.

### 경계 사례

- B를 A보다 먼저 설정하려고 함 → 안내.
- B ≤ A+0.2 → 반복을 시작하지 않고 메시지.
- audio.duration이 아직 로드되지 않음 → 설정 버튼 비활성.
- 타임코드가 없음 → 수동 A/B는 MP3만 있다면 사용 가능.
- 음원 전체 끝에서 반복 범위 지정 → `ended` 이벤트에서도 시작점 복귀 시도.
- 루프 활성 중 사용자가 탐색바를 이동 → 사용자의 탐색을 허용하되 다음 B 지점 도달 시 다시 A로 복귀.

## 7. 암기 모드

**목표:** 한국어 발음과 뜻을 처음부터 보여주는 대신, 기억을 떠올릴 기회를 만드는 것.

### 기본 동작

- 시작할 때 기존의 표시 토글 설정을 보존한다.
- 일본어 원문은 보이고 한글 발음·해석은 가린다.
- 줄을 누르면 가려진 발음·뜻이 나타난다.
- 다시 누르면 그 줄만 가린다.
- 암기 모드를 끄면 기존의 표시 토글 설정으로 돌아간다.
- 암기 모드의 줄별 공개 여부는 현재 연습 화면의 임시 상태(별도 저장하지 않음).

### 학습 완료 체크와 구분

- 가사 줄 자체를 누르는 것: 음원 이동/수동 선택/숨긴 내용 공개.
- 작은 체크 버튼을 누르는 것: **내가 외웠다고 표시**하는 개인 기록.
- 체크는 정답 판정이 아니다. 원하는 만큼 자유롭게 해제 가능.

## 8. 즐겨찾기/학습률

계산:

```text
학습 체크률 (%) = 반올림(현재 유효하게 남은 체크 line.id 개수 / 현재 JSON의 전체 줄 수 × 100)
```

- 줄이 0개면 0%.
- `song.id` 또는 `line.id`를 변경하면 브라우저 저장 기록과 연결이 끊어질 수 있으므로 데이터 편집 시 ID를 안정적으로 유지할 것.
- 저장소는 `localStorage`이고 외부 DB가 아니다.

## 9. 키보드 동작과 충돌 방지

| 키 | 기능 | 예외 |
| --- | --- | --- |
| `Space` | 재생/일시정지 | input/button/select/textarea 포커스 시 무시 |
| `←` | 5초 뒤로 | 음원 미등록/미로딩 시 효과 없음 |
| `→` | 5초 앞으로 | 음원 미등록/미로딩 시 효과 없음 |
| `R` | 현재 강조 줄 반복 | MP3 + 타임코드 필요 |
| `Esc` | 암기·집중 모드 종료 | 항상 가능 |

`Ctrl`/`Alt`/`Meta` 조합 키는 브라우저·운영체제 기능을 우선하므로 동작하지 않는다.

## 10. QA 핵심 포인트

- 타임코드 정확성: `00:01` 같은 문자열을 JSON 시각으로 넣지 말고 초 숫자 사용.
- 타임코드 없는 곡도 재생 자체는 가능(MP3가 있으면).
- MP3 없는 곡에서도 글/토글/암기/체크는 정상.
- 한 줄 반복과 수동 A–B 반복은 서로 다른 구간 상태를 공유하므로 새 설정이 이전 반복을 덮어쓴다.
- 1x로 돌아왔을 때 정상 속도가 되는지 확인.
- 새 노래로 이동 시 연습 기록은 저장되되 이전 곡의 A/B 설정은 가져가지 않는다.
- 빠른 시간 이동 중 가사 리스트가 의도치 않게 브라우저 전체를 스크롤하지 않는지 확인.
