# 22. 현재 상태·운영·검증

> 이 문서는 오류 수정 단계의 기록입니다. 이후 화면 단순화와 기능 제거 결정은 [23번 최신 결정](23_재생기_단순화_설정숨김.md)을 우선합니다. 아래 배속·암기·북마크·A–B·셔플·플레이리스트·패널 토글 관련 UI는 이후 제거했으며, 자료 관리 화면의 진입 링크는 숨겼습니다.

2026-10-12. 11번의 전체 설계와 이전 작업 기록을 기준으로 오류 수정 및 빠진 관리 기능을 구현했다. 현재 상태는 이 문서와 루트 README·TEST_RESULTS를 우선한다.

## 수정과 구현

- 서버·브라우저 가져오기·TXT·CLI가 `lib/song-schema.mjs`의 동일한 규칙으로 검사한다. 비문자열 발음/뜻, 빈 가사, 중복 id, 부분/겹침 타임코드, 잘못된 로컬 경로와 별칭 충돌을 거부한다.
- 곡별 로딩 오류를 분리한다. 잘못된 JSON이 있어도 유효한 곡과 화면은 유지하며 설정에 파일명·오류를 표시한다. 파일 목록 읽기 중 삭제된 파일도 전체 설정을 실패시키지 않는다.
- `PlayerProvider`의 실제 오디오 하나를 연습실·보관함·설정 미리듣기·공통 하단에서 제어한다. 페이지를 이동해도 재생 위치·음량·배속·A–B를 유지한다. 재생 오류에는 재시도와 자료 관리 연결을 제공한다.
- 선택된 보관함/플레이리스트 순서를 재생 큐로 전달한다. 이전/다음 곡과 이전/다음 가사 줄을 별도로 제공한다. 셔플은 순서를 한 번 정하며, 전체 곡 1회는 큐 끝에서 정지한다.
- localhost 전용 `/api/songs`로 실제 등록·편집·삭제한다. MP3 파일명을 id 기반으로 정하고 내용 검사·캐시 구분값을 적용한다. 편집 버전 충돌과 중복 등록을 거부한다. 저장은 임시 파일을 모두 준비한 뒤 교체하고 실패 시 원본을 복구한다.
- `/audio`·`/covers`는 로컬 파일 제공 API로 연결해 프로덕션 서버 시작 후 추가·복원한 파일도 즉시 제공한다. MP3는 Range 구간 요청과 HEAD·조건부 캐시를 지원하고 실제 등록 시 MP3 헤더·프레임 경계를 검사한다.
- 곡 삭제 전에 대상과 학습 기록 영향을 표시한다. 연결 MP3·커버는 보존하고 현재 재생 곡을 삭제하면 재생을 중단한다. 브라우저의 해당 곡 참조를 정리한다.
- 수동 가사·시간 편집과 탭 초안을 제공한다. 미완성 시간은 정식 JSON에 넣지 않으며 시간 없이 가사만 저장할 수 있다. 기존 곡·가사 id를 유지한다.
- 노트 편집/가사 연결, 단어 편집/검색/별표 필터, 플레이리스트 이름/순서 변경·곡 제거, 최신 추가순 정렬, 기본 보기/배속·개인 표시를 추가했다.
- 학습 기록 JSON 복원은 형식/버전/필드를 검사하고 없는 곡/줄을 미리 안내한다. 병합은 기존 설정·같은 id의 기존 항목을 유지하며 통계는 큰 값을 사용한다. 교체는 확인한 기록 전체를 적용한다.
- `/api/backup`으로 곡 JSON·MP3·커버 ZIP을 내보내고 복원한다. SHA-256, 허용 경로·파일 수/용량·압축 방식·중복 이름·SVG 활성 내용을 검사한다. 복원 미리보기 이후 자료 변경을 확인해 오래된 계획을 거부한다. 교체는 백업과 겹치는 파일만 바꾼다.
- 요청의 loopback URL/Host·동일 Origin·전용 헤더를 검사한다. 실제 읽은 요청 크기도 제한한다. 경로 밖 쓰기와 연결 폴더/파일 사용을 거부한다. Next가 내부 URL을 localhost로 정규화하는 경우에도 실제 Host를 검사해 127.0.0.1 요청이 정상 동작한다.
- 손상된 브라우저 저장 필드를 정리하고 원본을 복구 키에 보관한다. sessionStorage 저장 실패가 학습 기록 저장까지 막지 않도록 분리했다.
- 루트 README·테스트 결과·문서 인덱스를 현재 상태로 다시 작성하고 과거 문서는 작업 이력으로 구분했다. 사용하지 않는 초기 화면 코드는 제거했다.

## 운영 범위

음원·가사·커버는 로컬 파일이다. 클라우드, DB, 계정, 자동 번역/음역·가사 수집은 없다. 실행은 127.0.0.1 기본 바인딩을 유지한다. Git은 코드 보관이며 개인 학습 자료의 업로드 경로가 아니다.

음량·재생 방식·플레이리스트는 탭 세션, 나머지 학습/보기 기록은 v2 localStorage다. 기본 음량은 100%, 재생 방식은 전체 곡 1회다. 이전 v1은 보존한다. 복구용 원본 기록 키는 `gasabom:practice:recovery`다.

곡 삭제는 JSON과 현재 브라우저의 해당 학습 참조를 정리한다. MP3·커버를 자동 삭제하지 않는다. 다른 브라우저/탭에 저장된 학습 기록은 그 환경에서 관리한다. 파일 저장은 실행 중 실패에 대해 복구하며, OS/디스크 고장·강제 종료에 대한 완전한 다중 파일 원자성은 보장하지 않는다. 중요한 자료는 ZIP과 학습 기록 JSON으로 별도 보관한다.

## 남아 있는 자료 검수

Pretender의 원문·발음·뜻·타임코드는 전사 초안이다. `sourceAnalysis.reviewStatus=draft`, `timingStatus=estimated-from-local-audio`를 유지한다. 우선 검수 줄은 `line-011`, `line-026`, `line-054`, `line-056`, `line-061`, `line-070`, `line-071`, `line-073`이다. 공식 자료 대조/전체 청음 없이 완료로 표시하지 않는다. 음원·텍스트·가사 id와 이미 보정된 타임코드는 이번 오류 수정으로 바꾸지 않았다.

## 검증

검사 방법·최종 결과는 [TEST_RESULTS](../TEST_RESULTS.md)에 기록한다. 회귀 검사는 실제 음원이 없는 합성 입력과 임시 폴더로 수행하며 사용자 Pretender 원본을 변경하지 않는다. 브라우저 검수는 별도 포트에서 수행하고 임시 곡/기록을 정리한다.
