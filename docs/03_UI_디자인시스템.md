# 03. UI 디자인 시스템

## 1. 디자인 방향

**키워드:** 음악 다이어리 / 담백한 감성 / 일본어 읽기의 부담 경감 / 차분한 오디오 플레이어 / 한글 발음 중심.

- 시선을 끄는 대형 통계 관리자 화면이 아니라, 조용하게 몰입하는 **독서 + 음악 감상** 형태.
- 과도한 3D 조명, 네온 글로우, 두꺼운 그림자, 장식용 사진을 지양.
- 보랏빛은 '현재 부르고 있는 가사'와 '한글 발음'에만 의도적으로 사용.
- 사용자가 MP3만 제공해도 아름답게 보이도록 **CSS 기반 가상 앨범 아트**를 기본 제공.
- 개인적으로 준비한 실제 커버가 있으면 선택적으로 `coverSrc`로 표시.
- 외부 이미지/폰트 CDN을 필수화하지 않음.

## 2. 브랜드 규칙

| 요소 | 값 |
| --- | --- |
| 공식 이름 | **가사봄** |
| 라틴 표기 | `GASABOM` |
| 짧은 문구 | `읽을 수 없어도, 따라 부를 수 있게.` |
| 대표 서체 | 시스템 한국어 sans-serif: Pretendard 설치 시 우선, Noto Sans KR, Apple SD Gothic Neo 등 |
| 일본어 서체 | Yu Gothic, Hiragino Kaku Gothic ProN, Meiryo 등 시스템 폰트 |
| 로고 심벌 | 꽃잎 4개 + 노란 중심의 평면 벡터 심벌 (`components/Brand.tsx`) |
| 로고 표기 | 한글 가사봄 + 하단 소형 GASABOM |

### 상태 표현

- 재생 중인 현재 줄: 옅은 보랏빛 배경 + 진한 보랏빛 발음.
- 외운 줄 완료: 민트색 체크 원형 + 흰색 체크.
- 즐겨찾기: 연한 핑크 배경 + 핑크 하트.
- MP3 미등록: 붉은 강조가 아닌 **차분한 안내형 배너**(기능을 일부 사용할 수 있기 때문).
- MP3 재생 실패: 명시적 오류 텍스트 + 가이드 링크.
- 자동 동기화: 연녹색 `SYNC ON`, 시간 정보 없으면 중립 `MANUAL`.

## 4. 타이포그래피 계층

| 계층 | 데스크톱 목표 크기 | 강조 |
| --- | --- | --- |
| 홈 히어로 | 29~44px 반응형 | Bold 850, 넉넉한 행간 |
| 페이지 제목 | 약 25~36px | Bold 850 |
| 섹션 제목 | 21~25px | Bold 850 |
| 노래 카드 제목 | 15px | Bold 850 |
| 일본어 원문(가사) | 16px | Bold 760 |
| **한글 발음(가사)** | **15px** | **Bold 850 + 보라 강조** |
| 한국어 뜻 | 11px | 옅은 회보라색 보조 |
| 작은 버튼/태그 | 10~12px | 700~850 |
| 집중 모드 원문 | 22px | 확대 |
| **집중 모드 발음** | **20px** | 확대 |
| 집중 모드 뜻 | 14px | 확대 |

디자인 상 기본 가사 글씨는 컴팩트하지만, 작은 화면에서도 한글 발음의 시각적 선명도를 유지한다. 필요 시 `globals.css`에서 `.lyric-pronunciation` 크기를 개인 취향에 맞게 확대할 수 있다.

## 5. 여백·레이아웃

- 콘텐츠 최대 너비 약 1600px.
- 기본 페이지 좌우 여백 56px(좁은 화면 35px → 모바일 20px).
- 사이드바 폭 242px(작은 노트북 208px), 데스크톱에서 고정.
- 카드 모서리 11~19px, 히어로 21~23px.
- 가사 패널의 문장 행은 10px 이상 간격을 둬 클릭 범위를 분리.
- 연습실: 가사 `minmax(0,1fr)` + 오른쪽 팁 패널 267px.
- 오디오 플레이어는 데스크톱 사이드바의 오른쪽부터 화면 끝까지 하단 고정.
- 모바일에서는 전체 폭 하단 플레이어, 보조 컨트롤 일부 숨김.

## 6. 인터랙션 구성요소 명세

### 버튼

- Primary: 보라색 배경, 흰색 문자. 재생, 시작, 가이드 이동.
- Secondary: 흰 배경, 옅은 선. 즐겨찾기, 설정.
- Icon button: 원형 또는 정사각 패딩; **반드시 텍스트 대체명/툴팁**.
- Disabled: 불투명도 감소 + 실제 클릭 불가.

### 노래 카드

- CSS 아트워크: theme-violet/mint/peach/blue/midnight.
- 우측 상단 하트 아이콘(독립 버튼).
- 중간: 장르/난이도/제목/가수.
- 하단: 학습 비율 미니 진행바.
- 카드 전체를 클릭 가능하게 만들면서 하트 버튼을 중첩하지 않도록 이미지/제목만 링크.

### 가사 행

- 좌측 순번 + 체크 버튼.
- 가운데 3단 가사(일본어, 한글 발음, 뜻).
- 우측 반복 버튼.
- 클릭 시 배경 강조/선택 및 동기화 줄로 이동.
- 섹션 변경(1절/후렴/브리지) 시 상단에 구분 라벨.
- 암기 모드에서 가려진 발음/뜻을 행 클릭으로 확인.

### 하단 오디오 컨트롤

- 항상 재생/정지 버튼이 중심.
- ±5초 이동과 가사 줄 전후 이동은 역할 구분.
- 진행바는 드래그 가능한 기본 range input.
- 속도 선택 드롭다운, 음량 슬라이더.
- 구간 반복 활성 시 버튼 색상 변경.
- 모바일에서 하단 플레이어의 보조 도구 일부를 숨기되, **속도 선택은 가사 패널 상단에 별도로 유지**하고 핵심 재생 컨트롤은 계속 노출.

## 7. 모션·오디오 UX

- 카드 호버: 1~3px 수준의 위로 이동과 부드러운 그림자 변화.
- 가사 활성: 배경색 전환 약 190ms.
- 활성 줄 스크롤: 가능하면 현재 줄을 중앙에 가깝게 이동.
- 장시간 보기: 화면 전체 깜박임/글로우 효과 없음.
- `prefers-reduced-motion`일 경우 애니메이션과 부드러운 스크롤을 줄임.

## 8. 디자인 확장 규칙

새 기능 추가 시 UI의 주역은 **가사 텍스트**로 유지한다. 설정 버튼, 음원 관리 정보, 숫자 통계를 가사보다 크게 배치하지 않는다. 한글 발음 색/굵기 시스템은 모든 곡에 일관되게 적용한다.
