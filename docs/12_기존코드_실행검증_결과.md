## 수정·생성한 항목

- `package-lock.json`: 설치된 의존성 버전 고정.
- `tsconfig.json`: Next.js가 JSX 설정을 `react-jsx`로 자동 조정.
- `next-env.d.ts`: Next.js가 생성된 경로 타입 참조를 자동 갱신.
- `public/favicon.ico`: 준비한 승인 아이콘을 연결하여 실제 404 수정.
- 이 결과 문서와 [검증 기록 폴더](evidence/baseline-20261009/): 명령 로그, HTTP/브라우저 결과, 스크린샷.
