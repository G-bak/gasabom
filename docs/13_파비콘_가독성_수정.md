# 13. 파비콘 가독성 수정

2026-10-09 · 사용자 지적 후 수정 완료.

기존 ICO의 크기별 이미지 규격은 있었지만, 앱 아이콘의 연한 배경 타일과 여백을 그대로 축소해 탭에서 실제 음표가 작게 보였다. 32px 프레임의 파란 음표는 약 21×21px이었다. HTML에는 명시적인 아이콘 링크도 없었다.

승인된 SVG의 도형·색상을 유지하고 탭 전용 viewBox를 `52 39 172 172`로 조정했다. 배경 타일을 제외한 투명 심벌 중심으로 다시 출력했다. 32px PNG에서 파란 음표는 24×25px, 꽃잎까지 포함한 전체 도형은 30×29px로 표시된다.

- PNG: 16·24·32·48·64·96·128·256·512px.
- ICO: 16·24·32·48·64·128·256px 이미지 포함.
- SVG: `design/파비콘/SVG/가사봄_파비콘.svg` 및 `public/icons/favicon.svg`.
- `app/layout.tsx`: 16/32/48px PNG, 크기 제한 없는 SVG, ICO 대체 경로를 명시적으로 연결.
- 캐시 갱신: 아이콘 URL에 `v=2` 적용.
- 이전 파일: `design/이전시안/파비콘_여백많은_v1`에 보관.

데이터·타입·빌드 검사를 모두 통과했다. 서버를 재시작하고 실제 브라우저에서 아이콘 링크 5개와 각 경로의 HTTP 200, 올바른 이미지 형식을 확인했다.
