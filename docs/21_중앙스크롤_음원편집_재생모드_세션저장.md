## 현재 가사 중앙 스크롤

자동 스크롤을 켜면 현재 가사가 이미 화면 안에 있어도 다음 줄로 바뀔 때마다 가운데로 이동한다. 상단 메뉴와 하단 재생기를 제외한 가사 보기 영역의 가운데를 기준으로 한다. 재생 시작, 수동 줄 선택, 집중 보기·모바일 패널 전환에도 현재 줄을 맞춘다. 자동 스크롤 끄기 옵션을 유지하고 운영체제의 동작 줄이기 설정에서는 즉시 이동한다.

마지막 줄도 가운데에 올 수 있도록 필요한 만큼만 아래쪽 공간을 추가한다. 마지막 줄·메뉴·재생기의 크기 변화를 관찰하고 자기 자신의 여백 변화를 다시 관찰하지 않는다. 소수점 반올림으로 여백이 1px씩 바뀌며 렌더링과 다음 곡 전환을 방해하던 반복 계산을 제거했다.

## 재생 방식 네 가지

| 화면 문구 | 동작 |
| --- | --- |
| 전체 곡 한 번만 재생 | 현재 곡부터 보관함의 재생 가능한 곡을 순서대로 재생하고 마지막 곡에서 정지 |
| 현재 곡 반복 | 현재 곡이 끝나면 같은 곡의 처음으로 돌아가 재생 |
| 전체 곡 반복 | 보관함의 곡을 순서대로 재생하고 마지막 곡 뒤에는 첫 곡으로 돌아가 반복 |
| 현재 가사 줄 반복 | 현재 줄의 시작·끝 시간 구간을 반복 |

곡 순서는 현재 서버 보관함 목록의 제목 정렬을 따른다. 음원 경로가 없는 곡은 곡 재생 순서에서 제외한다. 현재는 Pretender 한 곡만 등록되어 있어 현재 곡 반복과 전체 곡 반복이 같은 곡을 다시 재생한다.

상단에 네 버튼을 분리하고 하단 재생기에도 같은 방식 선택을 연결했다. 방식을 선택하면 재생을 시작하거나 진행 중인 재생 방식을 바꾼다. 곡 전체 재생 방식으로 바꾸면 기존 줄/A–B 반복을 해제한다. 수동 A–B 구간 반복과 R 단축키, 줄별 반복 버튼, 단어 연결 구간은 유지했다. 타임코드가 없는 곡은 현재 가사 줄 반복을 사용할 수 없다.

곡 종료에 따른 다음 곡 이동에서는 공통 Provider의 일회성 요청으로 다음 연습실의 재생을 시작하고 배속·음량을 전달한다. 새로고침만으로 재생을 시작하지 않는다. 임의 페이지 이동 중 계속 재생하는 앱 전체 단일 오디오 구조를 완성한 것으로 보고하지 않는다.
