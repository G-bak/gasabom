# 23. 하단 재생기 단순화·설정 숨김

2026-10-12 최신 사용자 요청. 22번의 초기 오류 수정 작업 이후 아래 결정이 우선한다.

- 연습실 상단 `practice-toolbar` 플레이어를 제거한다. 오디오와 하단 플레이어는 앱 전체에서 하나만 유지한다.
- 기본 재생은 **현재 곡 반복**이다. 곡이 끝나면 같은 곡의 처음부터 재생한다. 이전 전체 곡 1회/전체 곡 반복 저장값은 현재 곡 반복으로 이관한다.
- 추가 재생 기능은 **현재 가사 줄 반복**만 남긴다. 하단 반복 아이콘으로 켜고 끄며, 해제하면 현재 곡 반복으로 돌아간다. 각 가사 행의 반복 아이콘도 유지한다.
- 암기 모드·북마크·셔플·A–B 구간·재생 속도·집중 모드·측면 패널 토글을 제거한다. 속도는 1배다. 노트·단어 패널은 항상 표시하며 모바일에서는 가사 아래로 이어진다.
- 하단 조작은 아이콘 버튼이다. 이전/다음 가사 줄, ±5초, 재생/정지, 줄 반복과 진행 위치·음량 조절을 제공한다. 재생 방식/배속 셀렉트를 렌더링하지 않는다.
- 보관함의 플레이리스트/연속 재생/셔플 UI를 제거한다. 검색·필터·카드/목록·학습 기록은 유지한다. 기존 북마크·플레이리스트 데이터는 삭제하지 않는다.
- 설정은 현재 쓰지 않으므로 메뉴·프로필·홈·보관함·하단의 진입 링크를 숨긴다. `lib/features.ts`의 `SETTINGS_VISIBLE=false`가 기준이다. `/settings`의 코드와 로컬 자료 관리 API는 보존하고 직접 주소 접근은 유지한다. 다시 사용할 때 이 값을 true로 바꾸면 진입 링크를 표시할 수 있다.
- 정상 화면에서 설정을 안내하는 가짜 등록 버튼이나 삭제한 기능을 홍보하는 문구를 표시하지 않는다.

현재 단축키는 Space 재생/정지, ←/→ 5초 이동, R 현재 줄 반복 켜기/끄기다. 입력창·버튼을 조작할 때 가로채지 않는다. 원문·발음·뜻과 song.id/line.id, 사용자 음원·학습 기록을 보존한다.

공통 검증·곡별 오류 격리·안전한 파일 관리·백업/복원·실시간 로컬 MP3/커버 제공은 유지한다. 자료 관리 화면은 숨겨진 상태다. 가사 자료는 계속 전사 초안이며 공식 대조·전체 청음 검수가 남아 있다.
