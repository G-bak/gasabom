00~10은 최초 기획·아키텍처·기술 참고 기록입니다. 초기 보라색 디자인, 예제 3곡, 웹 가이드, 등록 UI 제외, 당시 미검증 상태는 현재 기준이 아닙니다. 12~23은 이전 작업 이력을 보존합니다. 이 문서들의 “후속/미완료”는 해당 기록 당시의 상태이며 현재 상태는 24번과 테스트 결과를 확인합니다.

현재 표시하는 화면은 홈·보관함·연습실 세 가지의 정적 페이지입니다. 설정·서버 API는 제거되어 404입니다. 기본 현재 곡 반복과 아이콘형 줄 반복만 사용하며 이전 배속·암기·북마크·A–B·셔플·패널 토글·플레이리스트 UI는 제거했습니다. 현재 학습 자료는 사용자 제공 Pretender 한 곡이며 가사 검수는 초안입니다. 새로운 예제곡을 자동으로 추가하지 않습니다. 공개 Git에는 현재 곡의 MP3·JSON/TXT도 포함하며 모든 커밋 메시지에 곡 이름을 넣습니다.

디자인 원본과 당시 검수 캡처/백업은 로컬 보관 자료로 Git에서 제외합니다. 실행에 필요한 웹용 선택 에셋과 폰트 라이선스는 저장소에 포함합니다.

사용자는 요금제와 공개 범위를 확인한 뒤 저장소 공개 전환과 무료 GitHub Pages 배포를 요청했습니다. 사이트 주소는 https://g-bak.github.io/gasabom/이며 gh-pages에서 게시합니다. 곡 교체 커밋을 main에 올린 뒤 npm run deploy:pages로 사이트도 갱신합니다. 자세한 절차와 이전 결정 이력은 24번의 GitHub Pages 항목을 참고하세요.
