# 14. 새 디자인 적용 결과

2026-10-10 · 2단계 화면 적용 및 검수. 전체 기능 구현은 진행 중이다.

## 적용 결과

사용자 제공 시안 4장의 파란색·분홍색 디자인을 실제 Next.js 앱에 적용했다. 승인한 로고, 수정한 파비콘, 제작한 창가·도시 배경을 사용한다. 화면은 정적 시안 이미지가 아니라 실제 HTML·버튼·입력·로컬 데이터로 구성했다.

| 화면 | 적용 내용 |
| --- | --- |
| 홈 `/` | 상단 메뉴, 검색, 히어로, 학습 흐름, 기능 안내, 실제 보관함 곡 미리보기 |
| 보관함 `/library` | 검색, 장르/상태 필터, 정렬, 카드/목록, 즐겨찾기, 기본 플레이리스트와 실제 기록 통계 |
| 연습실 `/songs/[slug]` | 동일 가사 행의 일본어·한글 발음·뜻 3열, 상하 재생 도구, 배속·반복·암기·집중, 북마크, 기본 노트·단어장 |
| 설정 `/settings` | 파일 선택·드래그·검증·미리보기, TXT 변환, 실제 자료 목록, 보관함 관리 탭, 학습 기록 JSON 내보내기, 보기 설정 |
| 가이드 `/guide` | 새 디자인의 자료 작성·수동 등록·시간 정보·로컬 기록 안내 |

공통 상단과 하단을 연결했다. PC에서 가사는 같은 행 안의 3열로 정렬하고, 모바일에서는 한 줄의 원문·발음·뜻을 세로로 배치한다. 모바일 메뉴와 가사/노트·단어장 전환을 제공한다. 하단 재생기는 현재 연습실에서 사용할 수 있다.

배경은 `public/images/backgrounds/manifest.json`의 PC/모바일 크기와 AVIF/WebP를 선택한다. 기본 커버는 승인된 배경에서 잘라 만든 로컬 이미지다. 외부 이미지·폰트 서비스는 추가하지 않았다.

## 실제로 연결한 기능

- 공통 `PracticeProvider`를 통해 즐겨찾기·외운 줄·보기 옵션·북마크·노트·단어·플레이리스트·최근 재생·청취 시간을 저장한다.
- 기록은 `gasabom:practice:v2`에 저장하며 기존 v1 기록은 삭제하지 않고 이관한다.
- 곡별 노트 추가/삭제, 수동 단어 추가/삭제/별표/연결 구간 재생, 플레이리스트 생성/삭제와 곡 추가/제거를 제공한다.
- 통계는 실제 곡과 기록으로 계산한다. 시안의 예시 곡 수와 청취 시간을 고정 표시하지 않는다.
- 한글 발음 글자 크기, 표시 언어, 자동 스크롤 설정이 화면에 반영된다.
- MP3/JSON/TXT 선택과 미리보기, JSON 기본 검증, 수동 TXT 변환 및 JSON 다운로드를 제공한다. 선택 파일 상태는 ‘선택됨’이다.
- TXT/JSON에 적힌 음원이 보관함에 없을 때는 음원 요청 대신 MP3 선택 안내를 표시한다.

## 남은 전체 기능 구현

이번 결과는 2단계 디자인 적용 완료다. 확정된 전체 기능 범위는 [11번 설계](11_최신디자인_구현설계.md)를 유지한다.

1. 앱 공통 단일 오디오와 페이지 이동 중 재생 유지.
2. 로컬 파일의 실제 등록·편집·삭제, 공통 검증과 안전한 파일 저장, 수동 타임코드 편집.
3. 노트 수정/줄 연결, 단어 편집·검색, 플레이리스트 이름·순서 변경과 연속/셔플 재생, 나머지 개인 설정.
4. 곡 자료 ZIP 백업, 학습/곡 자료 복원과 충돌 처리, 전체 시나리오 검수.

현재 파일 등록 화면은 선택·미리보기·변환까지 동작한다. 새 곡을 보관함에 넣으려면 가이드에 따른 수동 파일 등록을 사용한다. JSON 내보내기는 제공하며 복원과 곡 자료 ZIP은 아직 제공하지 않는다.

## 실행

현재 프로덕션 서버를 `127.0.0.1:3000`에서 실행해 두었다. 재실행은 프로젝트 폴더에서 `npm run start`를 사용한다. 소스를 수정한 경우 `npm run build` 후 서버를 다시 시작하거나 개발 중에는 `npm run dev`를 사용한다.
