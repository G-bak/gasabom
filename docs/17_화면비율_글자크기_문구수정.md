# 17. 화면 비율·글자 크기·문구 수정

2026-10-10 사용자 요청 반영. 고정 최대 너비와 콘텐츠 최대 높이를 다시 도입하지 않고 넓어진 화면에 맞춰 요소를 조정했다.

## 화면 비율

- 홈: 소개 영역과 카드 영역을 1:4로 배치하고, 제목·버튼·섹션 간격을 확대했다. PC 히어로 높이는 화면 폭에 맞춰 늘어나며 내용이 많으면 더 확장된다.
- 홈 곡 카드: 이미지 비율을 PC 2.2:1, 모바일 1.6:1로 바꿔 넓은 화면에서 커버가 지나치게 높아지지 않게 했다.
- 보관함: 메뉴·곡 목록·통계의 비율을 0.8:4:1.2로 조정했다. 큰 화면에서 카드 열 수는 4열, 2200px 이상은 5열이다. 목록 보기도 유지한다.
- 연습실·설정: 본문과 도구 영역을 4:1로 배치했다. PC 도구 영역은 최소 320px이며 화면에 맞춰 확장된다. 좁은 화면에서는 기존 탭/세로 배치로 전환한다.
- 버튼·검색·재생기·로고·노트 입력창·파일 선택 영역의 크기와 간격을 조정했다. 모바일 학습 카드는 번호/아이콘과 설명을 두 열로 배치한다.

## 글자 크기

Pretendard 로컬 파일을 유지하고 화면 폭에 따라 크기를 조절한다.

| 항목 | 모바일/작은 화면 | 넓은 PC |
| --- | --- | --- |
| 본문 | 16px부터 | 2560px에서 20px |
| 보조 글자 | 14px부터 | 2560px에서 18px |
| 카드 제목 | 18px부터 | 최대 24px |
| 홈 제목 | 모바일 32px | 최대 56px |
| 한글 발음 | 사용자 설정 유지 | 기본 24px, 20~32px 조절 |

1920px 본문은 18.8px, 1440px은 17.6px로 확인했다. 안내 문장의 색상도 읽기 쉽도록 조정했다. 한글 발음의 설정값은 화면 크기 때문에 임의로 변경하지 않는다.

## 문구

홈·보관함·연습실·설정·가이드·공통 상단/하단의 서비스 문구를 기능 중심의 한국어로 정리했다. 사용자 곡의 제목·원문·발음·뜻은 수정하지 않았다.

| 기존 | 변경 |
| --- | --- |
| 좋아하는 노래가, 더 넓은 세상을 열어줘요. | 내 노래 보관함 |
| 좋아하는 노래로, 조금 더 좋아하는 나에게. | 가사봄 · J-POP 가사 연습 |
| 더 깊이, 더 효과적으로 연습할 수 있는 기능 | 반복·배속·암기 연습 |
| 좋아하는 노래, 내 연습실에 담기. | 곡 추가 및 연습 방법 |
| KEEP YOUR MUSIC JOURNEY | 학습 기록 |
| 나에게 편한 연습 화면 | 가사 표시 설정 |

장식용 영어 슬로건과 커버의 영문 문장을 제거했다. ‘한국어 해석’은 ‘한국어 뜻’, ‘SYNC ON/MANUAL’은 ‘자동/수동’으로 표시한다. 홈의 ‘연습할 곡 선택’은 보관함으로, ‘예시곡 연습’은 실제 예시곡으로 연결한다.
